# 0.4.0.4 频率／分频／电压读取修复

验证日期：2026-09-08。输入文件 `Cat girl memoryOC (2).exe` 的 SHA256 为 `7BBC3E2EDA15A61D187785AAC64AC1F63F9FE6DD06CC600449D60FCA9866A90D`，与上一版 0.4.0.3 完全相同。

## 已确认的原因与修复

1. 本机 `Set Mem Clock` 的 GetMinMaxSteppingValues 是全零占位数据；有效的 MCLK 4000 在 Getdvalues.Current 中。旧读取逻辑丢弃了该字段，并把 Windows 配置频率当成固件值。新版按响应 ID／Length 选取正确来源，移除该替代路径。
2. 原界面显示 DDR 数据率，却把无前缀数字按 MCLK 解析。新版将 6400 转成 MCLK 3200，并允许显式 MCLK 输入；旧配置数字会带上 MCLK 前缀保存其原含义。
3. 旧分频三项中的 Auto 和 1:2 实际使用同一个 DIV1 关闭编码。新版只显示“同频”“分频”，并明确分频仅是 DIV1=0，不保证强制半频。
4. 新分频控件只在用户菜单点击时提交，首次需确认本次会话；重复选同一项不受 IsModified 过滤。初始化／绑定／刷新／载入／菜单开关不会触发发送。每次接收的手动选择只形成一个 UCLK 请求，固件缓冲开始/结束为额外的协议命令；没有参数重试。
5. 电压读取匹配范围表中的 Current。正数显示 V，0 显示 Auto／未实测，SoC 非零显示原始 VID；不把目标值或未知编码作为实时电压。
